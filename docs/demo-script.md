# Demo 视频脚本

目标时长：2～3 分钟。录制时只使用比赛允许的公开或合成文档。

## 0:00～0:20 启动与状态

1. 展示 `docker compose up --build`。
2. 打开 `/api/status`，展示文档数、分块数、模型和阈值。
3. 打开 Web UI。

## 0:20～1:10 有依据问答与引用

1. 提问一个能由文档明确回答的问题。
2. 展示流式答案和来源卡片。
3. 点击来源，展示 `文档路径 + anchor` 对应的原始证据。
4. 强调引用由检索元数据生成，不由 LLM 自报。

## 1:10～1:35 明确拒答

1. 提问一个文档集中不存在答案的问题。
2. 展示固定拒答文案。
3. 展示该回答没有调用 LLM 的日志或追踪记录。

## 1:35～2:20 增量更新

1. 新增一篇 Markdown 文档并立即提问。
2. 修改其中的关键事实后再次提问。
3. 删除文档后再次提问，展示系统拒答。
4. 画面中保留时间，证明更新在 5 分钟内生效。

## 2:20～2:50 架构与复现

1. 快速展示 `docs/architecture.md` 数据流。
2. 展示统一网关环境变量，注意隐藏密钥。
3. 展示 `31 passed` 的测试结果和自测报告。
