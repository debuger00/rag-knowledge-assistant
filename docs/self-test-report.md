## 指标定义

| 指标 | 定义 |
|---|---|
| Answer Accuracy | 可回答问题中答案正确的问题数 / 可回答问题数 |
| Refusal Precision | 正确拒答数 / 所有拒答数 |
| Refusal Recall | 正确拒答数 / 应拒答问题数 |
| Citation Coverage | 带至少一个有效引用的非拒答回答数 / 非拒答回答数 |
| Citation Validity | 能通过引用 API 定位的引用数 / 全部引用数 |
| Update Latency P95 | 文档变更到查询可见延迟的 95 分位 |

## 正式评测执行步骤

1. 固定代码提交、模型、阈值和文档集版本。
2. 清空 Chroma 卷并全量重建索引。
3. 执行公开问答集，保存结构化响应，不保存敏感 Prompt 正文。
4. 计算上述指标并记录失败样本类别。
5. 执行新增、修改、删除测试各 30 次，报告 P50/P95/最大延迟。
6. 将真实结果更新到本报告。
